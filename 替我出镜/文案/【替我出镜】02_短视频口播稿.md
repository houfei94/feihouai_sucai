# 替我出镜 · 短视频口播稿（3 条）

> 每条均按「钩子 → 痛点 → 方案 → 证明 → 行动」推进，单句 ≤ 20 字，可直接配音。
> 画面对应：产品界面录屏 + 成片展示，成片画面至少占 40%。

---

## 稿一 · 痛点共鸣型（约 45 秒 · 视频号 / 朋友圈）

【钩子】
有观点，却不敢出镜，这条视频送给你。

【痛点】
镜头前紧张，忘词，要重录。
文案写好了，还要剪字幕、配音乐。
一条视频，两小时起，发不发都不甘心。

【转场】
其实你只需要写文案。

【方案】
粘贴你的口播稿。
AI 自动拆分页，配好动效。
克隆你的声音，它替你讲。
三分钟，成片就出来了。

【证明】
字幕跟着语音走。
封面三尺寸自动生成。
不露脸，不出镜，不剪辑。

【行动】
想要演示的，评论区扣「口播」。
我把成片发给你看。

## 稿二 · 效率对比型（约 40 秒 · 抖音 / 视频号）

【钩子】
一条口播视频，别人忙两天，我三分钟。

【对比】
自己拍：布景、打光、忘词、重录，两小时起。
找代剪：沟通、等交付，半天到一天，几十上百一条。

【方案】
你写文案，或者让 AI 帮你写。
系统自动拆分页、配动效。
用你自己的声音配音。
三分钟出片，几毛钱一条。

【证明】
30 多种版式，自动匹配。
抖音、视频号、公众号都能发。
本地部署，文案不外传。

【行动】
想做但一直没开始的，
评论区扣「1」，我发演示。

## 稿三 · 15 秒强钩子（投流 / 前贴片）

【钩子】
不敢露脸，也能做口播视频。

【卖点三连】
文案进去，成片出来。
克隆你的声音，AI 替你出镜。
三分钟一条，成本几毛钱。

【行动】
有观点，就值得被看见。
演示视频，评论区自取。

## 拍摄建议

| 项 | 建议 |
|---|---|
| 画面 | 前 3 秒放成片（视觉冲击），中间录屏演示，结尾再放 2 秒成片 |
| 字幕 | 数字与关键词高亮（3 分钟、几毛钱、30+ 版式、不露脸） |
| 节奏 | 每 3~5 秒切换画面，成片片段可多机位式重复出现 |
| 首帧 | 直接用 `海报/01_主视觉`，保证封面即信息 |
| 声音 | 配音务必用克隆音色，与本人口播形成"一致性"说服力 |
| 合规 | 不做「保证涨粉/变现」承诺；成本数据标注为 API 成本口径 |
